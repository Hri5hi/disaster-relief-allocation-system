# Disaster Relief Resource Allocation System

## Overview

The Disaster Relief Resource Allocation System is a Database Management System project developed as part of the **23CSE202 - Database Management Systems** course at **Amrita School of Computing**.

The system helps disaster management authorities efficiently manage:

- Disaster zones
- Relief shelters
- Resource inventory
- Volunteers
- Affected people
- Resource allocation
- Donations
- Distribution tracking
- Reports and analytics

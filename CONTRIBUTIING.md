# Contribution Guidelines

## Branch Strategy

- main
- dev
- feature/<feature-name>

Never push directly to main.

---

## Commit Messages

Examples

```
feat: add volunteer module
db: create shelter table
fix: resolve login issue
docs: update README
```

---

## Pull Requests

- Every feature must be developed in a feature branch.
- Open a Pull Request into `dev`.
- Another team member must review before merging.

---

## Coding Standards

- Use meaningful variable names.
- Keep SQL inside DAO classes.
- Keep business logic inside Service classes.
- Write clean and readable code.
